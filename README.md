# SpacePlants Lab 🌱🚀

**NASA Space Apps Challenge 2026 · Challenge: Space Mission Design Game**

A serious web game where you design a space growth module, grow real plants that NASA has harvested in space, and keep them alive through 5 minigames.

## ▶️ Play now (no download needed)
**https://erick-ucsm.github.io/SpacePlants-Lab/**

Works in Chrome, Edge and Firefox on a computer. The first load takes a few seconds.
Language: English by default · Spanish available in **Settings → Language**.

## How to play
1. Choose a seed: red romaine lettuce, mizuna, kale, radish or chile pepper.
2. Design your module: green border = recommended, red = not recommended, gray = neutral.
3. Keep light, water, humidity, temperature and oxygen in range by winning minigames.
4. Harvest on time with more than 80% plant health.

## Minigames
| Variable | Minigame |
|---|---|
| Light | Tic-tac-toe |
| Water | Spacecraft sliding puzzle |
| Humidity | NASA pioneers memory game |
| Temperature | Extreme temperatures puzzle |
| Oxygen | Whack-an-alien |

## Built with
- Godot Engine 4.7 (GDScript, Compatibility renderer)
- Web export (HTML5 / WebAssembly)
- Data from NASA Veggie, Advanced Plant Habitat and Artemis missions
